# CleverTap Unity SDK Assignment

## Overview
This repository contains:
- A Unity Package Manager (UPM) SDK for displaying platform-native messages
- A sample Weather application demonstrating SDK usage

## Contents
- Packages/com.clevertap.sdk → Unity SDK
- Assets/Samples → Sample Weather app

## How to Run
1. Open the project in Unity 2021.3 LTS or later
2. Open the WeatherSample scene
3. Press Play (Editor) or build to Android/iOS

## Platforms Tested
- Android
- Unity Editor
- iOS (native alert)

## Notes
- Latitude and Longitude are hardcoded for demo purposes
- Can be replaced with GPS using Input.location
